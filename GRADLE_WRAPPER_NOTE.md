# Gradle Wrapper / Windows Build Note

The release declares Gradle 8.11.1 in `gradle/wrapper/gradle-wrapper.properties`.

The release intentionally includes a resilient Windows bootstrap path because some artifact pipelines omit binary wrapper JAR files. `scripts/BUILD_WINDOWS.ps1` now:

1. Uses the project wrapper when `gradle-wrapper.jar` is present.
2. Otherwise uses a system `gradle` executable if available.
3. Otherwise downloads the declared Gradle 8.11.1 distribution into `.gradle-bootstrap` and generates the project wrapper locally.
4. Runs `gradlew.bat --version`, unit tests, and the debug APK build.

The official Gradle documentation recommends using the Wrapper for reproducible builds. The wrapper JAR is normally generated by the `wrapper` task rather than manually downloaded.
